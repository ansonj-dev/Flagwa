# Open-source and Reuse Status

## Repository status

The repository is hosted at [ansonj-dev/Flagwa](https://github.com/ansonj-dev/Flagwa). The checked main-branch repository did not contain a top-level software licence file at the time of this documentation update.

**Until a licence is selected and committed, all rights are reserved by default.** Public visibility or a GitHub repository does not automatically grant permission to copy, modify, distribute, sublicense or commercially use the source code.

This status is documented rather than assigning a licence without the project owner's decision.

## Before declaring an open-source release

1. Confirm ownership and contributor rights for all source files.
2. Choose a licence that matches intended governance and downstream use.
3. Add the full licence text in a root `LICENSE` file.
4. Add third-party notices for bundled code, fonts, artwork and other assets as applicable.
5. Keep code licence separate from imagery, NISAR data and contextual datasets.
6. Review provider redistribution terms before committing downloaded datasets.
7. Add contribution, conduct and security reporting guidance.

## Data and code are different

A software licence does not automatically cover NISAR source products, satellite imagery, contextual GIS datasets, map tiles/basemaps, fonts, icons, third-party packages or generated products subject to source-data conditions.

See [Data Sources & Attribution](DATA_SOURCES.md).

## Badge guidance

Do not add an MIT/Apache/GPL badge until that licence is actually present in the repository. Use a neutral status badge or omit it.
